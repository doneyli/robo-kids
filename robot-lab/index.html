🔌 Robot not connecting?

Everything in here works without him — the on-screen robot mirrors every command, so a session never has to be cancelled.

When you do want the real thing:

  1. Power him on and give him about a minute to join the wifi.
  2. Make sure this device is on the same network.
  3. Tap the chip in the top right to retry.
  4. Still nothing? Open http://reachy-mini.local:8000 in a new tab. If his dashboard loads, the robot is fine and it is this page that cannot see him.

This page must be served over plain http://, not https://. A secure page is not allowed to talk to an insecure robot, and the robot does not do HTTPS. That is what serve.sh is for.
